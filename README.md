# poe2_tools

《流放之路 2》（Path of Exile 2）半自动化辅助工具。核心设计原则：**人脑负责导航与高阶决策，脚本负责高频机械执行**。明确拒绝全自动化 Bot（不做自动寻路、自动探索地图、全自动刷宝）。

## 功能列表

### Python 桌面端（tkinter，自动化工具）

- **战斗宏**：配置1-4 + 旋风页，每键可配策略（禁用 / 连点 / 按住不放）、执行间隔、随机抖动；10ms 节拍调度、到期时间驱动；失焦自动停止
- **旋风 Q/E 数字检测**：技能图标出现充能数字时自动按键（OpenCV 模板匹配，白色像素兜底），边沿触发不连按
- **背包整理**：F3/F4 两点标定格距 + 一键存仓（Ctrl 按住行优先遍历点击）
- **货币坐标管理**：坐标页标定 10 种货币，三级货币只需标定一级
- **石碑速点**：Shift+右键选货币 → 背包逐格左键 → 完成后自动触发背包整理
- **地图速点**：点金×1 → 崇高×4 → 瓦尔×1 → 完成后自动整理
- **F12 全局急停**：中断全部任务并释放所有按键

### 经济记录 Web 应用（信息记录统计）

- 记录 poe2db.tw 14 个经济模块的价格快照（赛季管理、历史筛选、定时抓取）
- 交易助手：最优兑换路径与套利环检测
- 信息库：物品 Currency Exchange 金币值与双语检索

桌面端与 Web 应用完全独立，互不影响。

## 环境要求

- Windows 11 原生环境（禁止依赖 WSL）
- Python 3.11+
- [uv](https://docs.astral.sh/uv/)（环境与依赖管理）

## 安装

```bash
uv sync
```

## 启动

```bash
uv run python main.py          # 桌面端主界面（tkinter，自动化工具）
uv run python -m web.app       # 经济记录 Web 应用（http://127.0.0.1:8321）
```

桌面端首次启动时，若存在旧版 AHK 配置（`ahk/poe2_key_helper.ini`）会自动迁移到根目录 `poe2_tools.ini`。

## 测试

```bash
uv run pytest
```

纯逻辑（网格计算、配置读写、热键解析、调度、迁移等）有 pytest 单元测试覆盖；游戏内行为依赖人工验证。
