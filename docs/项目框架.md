# 项目框架

> 项目文档：记录 poe2_tools 的整体框架。结构变化时同步更新本文档。

## 定位

POE2 半自动化辅助工具（Copilot）：人脑负责决策，脚本负责高频机械执行。不做全自动化 Bot。

## 技术栈

| 项 | 选型 | 说明 |
|----|------|------|
| 语言 | Python 3.11+ | 纯 Python，无 AHK |
| 环境管理 | uv | `uv sync` 安装依赖 |
| GUI | tkinter / ttk | 标准库，后续功能丰富后迁移 Qt |
| 输入模拟 | pydirectinput / keyboard / mouse | 与 poe1_tools 一致 |
| 测试 | pytest + 人工游戏内验证 | 纯逻辑单测，行为人工验证 |

## 目录结构

```
poe2_tools/
├── main.py                 # 入口
├── poe2_tools/             # 功能包
│   ├── common.py           # 共享基础：ini 读写（UTF-8）、POE2 窗口检测、任务状态、按键释放
│   ├── bag.py              # 背包整理：标定、网格计算（grid_points）、一键存仓
│   ├── combat.py           # 战斗巡航：多按键连点/按住、失焦自动停止
│   └── ui/                 # tkinter 界面层
│       ├── app.py          # 主窗口 + 全局热键注册 + 状态/日志区
│       ├── bag_tab.py      # 背包整理
│       ├── combat_tab.py   # 战斗
│       └── placeholder_tab.py  # 占位页（地图/装备复用）
├── tests/                  # pytest 单元测试（纯逻辑）
├── docs/                   # 项目文档 + 功能文档
├── changelog/              # 变更明细，超 10 个合并进 CHANGELOG.md
├── response.md             # 最近一次问答记录
├── promot/                 # 需求与设计草稿
└── pyproject.toml / uv.lock
```

## 模块规划

| 模块 | 复用来源 | 状态 |
|------|----------|------|
| 背包整理 | 已迁移 `poe1_tools/poe_tools/bag.py`（复制适配） | 已人工验证 2026-09-13 |
| 战斗 | 已迁移 `poe1_tools/poe_tools/combat.py`（复制适配） | 功能完成，待游戏内人工验证 |
| 地图 | — | 占位 |
| 装备 | — | 占位 |

坐标体系已确认与 POE1 一致：两点标定 CellSize，`Grid[row][col] = (originX + col*CellSize, originY + row*CellSize)`。

## 演进方向

- 背包整理 / 战斗：迁移 poe1 功能代码并适配 POE2 窗口
- 配置持久化：纯 Python，不受 UTF-16 LE 限制（可选 UTF-8 ini / TOML，迁移时定）
- GUI：tkinter → Qt（功能丰富后）
