# 功能说明

> 功能文档：解释各模块功能及使用方式，含待完成清单（人工验证后更新状态）。

## Python 桌面端（tkinter，`poe2_tools/`）

桌面端已于 2026-10-01 从 AutoHotkey v2 全量迁回 Python 分层架构（`poe2_tools/`：config / core / modules / bridge / ui），功能与 AHK 版等价。执行 `uv run python main.py` 启动；配置存于根目录 `poe2_tools.ini`（UTF-8）。首次启动时若存在旧版 AHK 配置（`ahk/poe2_key_helper.ini`）会自动迁移。旧 AHK 版保留在 `ahk/` 目录作回退对照，人工验证通过后删除。

界面分为：运行状态区（POE2 前台 / 战斗 / 整理 / 石碑 / 地图 / 当前配置）、配置标签页（配置 + 旋风 + 坐标）、右侧功能设置区、共享日志区。

### 战斗宏

1. 界面含 1 个配置页，8 个按键行：左键、右键、空格、Q/W/E/R/T
2. 每个按键可配：策略（禁用 / 连点 / 按住不放）、执行间隔（毫秒，下限 50）、随机抖动（±15%）
3. 战斗宏启停热键默认 `F2`，仅 POE2 窗口前台时生效；启动时连点键首次触发随机错开避免同帧
4. 连点由 10ms 调度器按到期时间驱动（pydirectinput / DirectInput 扫描码发送），间隔精确不漂移；POE2 窗口失焦自动停止并释放所有按住键；`F12` 全局紧急停止并释放 Ctrl/Shift/Alt/鼠标键

### 背包一键存仓

1. 游戏窗口内：鼠标指向背包第 1 格中心按 `F3`，指向右侧相邻格中心按 `F4`，格子间距自动保存
2. 行数 / 列数 / 整理间隔在右侧"功能设置"区调整（默认 5 × 11，间隔默认 30ms、±30% 随机抖动，范围 5-5000ms；整理为快速操作：鼠标瞬间移动 + 直接点击）
3. 鼠标放到第 1 格中心，按整理热键（默认 `F1`）开始：按住 Ctrl 按行优先遍历点击；整理中再按一次热键停止
4. 整理中窗口失焦或按 `F12` 自动中断并释放 Ctrl

### 旋风配置（数字检测触发）

「旋风」标签页是战斗宏的特殊配置页，用同一个战斗热键（默认 `F2`）启停：

1. 鼠标左 / 中 / 右键：与普通配置页相同，可配策略（禁用 / 连点 / 按住不放）、间隔、随机抖动
2. Q / E 技能改为**数字检测触发**：技能图标左上角出现数字（充能数）时自动按一下
   - ① 标定：点该行「标定」→ 游戏内鼠标指向技能图标上的数字按 `F5`（确定搜索范围中心，±30px）
   - ② 截图：点该行「截图」在标定点直接截取模板图，保存为 `templates/q.png`、`e.png`（不再需要 FindText 字库代码）
   - ③ 检测：有模板图时用 OpenCV 模板匹配（阈值 0.9，≈ FindText 容错 10%），未截图时用白色像素兜底；每 2 秒一次（测试阶段）
   - 边沿触发：数字从消失到出现只按一次，不会连按
   - 检测由独立后台线程执行，检测日志输出到界面日志区；全黑帧（截图失败）保持上次状态不误判

### 坐标页（货币坐标管理）

「坐标」标签页集中管理所有脚本用到的货币坐标，从 ini（`[Currency]` 节）读取并展示（双列布局：左列三级货币、右列普通货币）：

- 三级货币：蜕变 / 增幅 / 富豪 / 崇高 / 混沌，只需标定**一级**坐标；二级 = 一级 +70px、三级 = +140px（向右推导）
- 普通货币：点金石 / 瓦尔 / 磨刀石 / 护甲片 / 奥术师
- 标定方法：点该行「标定」→ 切到游戏窗口，鼠标指向该货币按 `F5` 记录（再点一次「标定」取消）；坐标立即写入 ini 并刷新显示

### 石碑速点

按住 Shift → 移动到所选货币坐标右键选中 → 移动到背包逐格左键 → **完成后自动触发一次背包整理**，批量把货币应用到石碑/装备上：

1. 「坐标」页标定所用货币坐标，F3/F4 标定背包格距
2. 功能设置区选择石碑货币与级别（级别仅对三级货币生效）、石碑间隔（默认 50ms，±30% 抖动，范围 5-5000ms）
3. 游戏内鼠标放到背包第 1 格中心，按石碑速点热键（默认 `F6`）开始；再按一次停止
4. 失焦或按 `F12` 自动中断并释放 Shift（中断时不触发整理）

### 地图速点

按顺序执行：点金石×每格 1 次 → 崇高×每格 4 次 → 瓦尔×每格 1 次 → **完成后自动触发一次背包整理**，批量给地图上点金/崇高/瓦尔：

1. 「坐标」页需已标定：点金石、崇高（一级）、瓦尔；F3/F4 标定背包格距
2. 地图间隔单独配置（默认 50ms，±30% 抖动，范围 5-5000ms）
3. 游戏内鼠标放到背包第 1 格中心，按地图速点热键（默认 `F7`）开始；再按一次停止
4. 每个阶段都是"Shift 按住 → 货币坐标右键选中 → 背包逐格左键 N 次"；失焦或 `F12` 中断（中断时不触发整理）

修改配置后点"保存配置"生效（热键即时重注册）；关闭窗口自动保存并退出。

## 经济记录（Web 应用）

独立的 Web 应用，记录 poe2db.tw 14 个经济模块的价格快照，与桌面工具互不影响。

### 启动

`uv run python -m web.app`，浏览器打开 http://127.0.0.1:8321 。

### 使用方式

1. 首次使用在「赛季管理」面板录入赛季名称与开服日期（如 0.5.5闪回 / 2026-09-04）；左侧赛季列表默认选中当前赛季（开服日期最新者），新旧赛季数据都保留可查
2. 左侧选择经济模块（通貨/碎片/祭祀等 14 个），点「刷新本模块」抓取该模块当前价格；刷新中按钮转圈禁用
3. 表格复刻原站：图标 + 繁体名 + 英文小字 + Wiki 链接、24h Value（含 ≈N 混沌换算）、7 天迷你走势 + 红/绿涨跌幅、24h 交易量
4. 表头点击可按价格/涨跌幅/交易量排序（升降切换）；搜索框同时匹配中文与英文名
5. 「开服天数」下拉筛选历史快照（开服天数 = 快照日期 - 开服日期 + 1），默认最新
6. 「定时抓取配置」面板：开关、开服 ≤ N 天（默认 14）每天定时抓、之后每周定时抓；保存后立即生效
7. 价格基准为神圣石；抓取「通貨」模块时自动更新混沌⇄神圣汇率，其他模块价格据此换算出 price_chaos

### 交易助手（左侧边栏「工具」区）

根据用户在游戏内观测并手动录入的兑换比例，计算最优兑换路径与套利机会，目标是根据差价快速积攒通货。所有录入永久保存（`trade_rates` 表），为后续智能优化积累数据。

1. **三通货市场比例**：分「买入」「卖出」两部分平铺录入。买入需付金币（金币 = 买入数量 × 该通货 Currency Exchange 值），行内实时显示金币费；卖出免金币。同方向买卖价差分别录入，重复录入以最新一条为准，旧记录保留在历史中
2. **Currency Exchange 值（金币/个）**：崇高/混沌/神圣各一个费率，优先取信息库 wiki 抓取值，可手动覆盖（清空恢复信息库值）
3. **金币 ⇄ 通货转化比例**：由费率直接推导（1 通货 = VE 金币，1 金币 = 1/VE 通货），并按最优路径折成混沌展示
4. **物品兑换比例**：任意物品与三通货之间的比例，3 通货 × 买卖 2 方向共 6 行全部平铺展示；物品名带已抓取物品的名称联想
5. **最佳兑换方案**：以每个方向+买卖侧的最新比例构建汇率图，简单路径 DFS 求三通货两两之间兑换率最高的路径（可绕行物品）；买边按有效汇率（扣除金币费折算）计算，路径中买边标 [买]
6. **套利机会**：自动枚举乘积 > 1 的兑换环，按收益率降序展示；计入金币费后的伪套利（看似赚钱实则被金币费吃掉）不会被报出
7. **录入历史**：最近 30 条记录（含买/卖类型），误录可删除
8. 计算逻辑在 `web/trading.py`（纯函数），单测覆盖最优路径、套利环与金币费折算

### 信息库（左侧边栏「工具」区）

物品基础信息库，数据来自已抓取的经济模块物品 + 各物品 wiki 页（poe2db.tw），为后续交易分析提供金币消耗数据。

1. 表格列：图标 + 中/英文名、所属模块（中文名 + 英文 slug）、**Currency Exchange**（游戏内市场交易时每单位物品消耗的金币，如神聖石 800 金币）、Wiki 外链、信息抓取时间
2. 「抓取 Wiki 信息」：后台线程逐个请求有 wiki 链接且尚未抓过的物品页（限速 ≥ 1 秒/次），从属性表 `Currency Exchange` 行提取金币值入库（`item_info` 表）；进度实时展示，单个物品失败不中断
3. 「全部重抓」：忽略已有数据全部重新抓取（版本更新金币值变化时用，耗时较长）
4. 搜索框对物品中/英文名、模块中/英文名（slug）、wiki_slug 做服务端模糊检索（防抖 300ms）；模块下拉可过滤单个模块；金币列表头点击可排序
5. wiki 页同时提取 BaseType 中/英文名称存库（`item_info.name_zh/name_en`），展示时优先于经济页名称，保证中英文都可被检索
