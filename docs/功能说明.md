# 功能说明

> 功能文档：解释各模块功能及使用方式，含待完成清单（人工验证后更新状态）。

## 主界面

执行 `uv run python main.py` 启动，窗口分四个标签页。

### 背包整理

- 整理热键设置（默认 F1）
- 背包行数 / 列数设置（默认 5 × 11）
- 功能目标：以鼠标当前位置为第 1 格中心，按网格依次 Ctrl+点击，将物品转移到仓库

### 战斗

- 启停热键设置（默认 F2）
- 支持按键：鼠标左键、鼠标右键、空格、Q/W/E/R
- 每个按键独立配置策略（禁用 / 连点 / 按住不放）与执行间隔（默认 300ms）

### 地图 / 装备

占位模块，暂不开发。
