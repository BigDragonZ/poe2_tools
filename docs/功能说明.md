# 功能说明

> 功能文档：解释各模块功能及使用方式，含待完成清单（人工验证后更新状态）。

## AHK 按键助手（新桌面端，`ahk/poe2_key_helper.ahk`）

由于 Python 键鼠模拟在 POE2 中适配性一般，桌面端功能（战斗宏 + 背包整理）已用 AutoHotkey v2 重构，参考 D3KeyHelper v1.4 实现。需安装 AutoHotkey v2（本机已装 2.0.26），双击 `ahk/poe2_key_helper.ahk` 启动；配置存于 `ahk/poe2_key_helper.ini`（UTF-8）。

### 战斗宏

1. 界面含配置 1-4 四个配置页，每页 8 个按键行：左键、右键、空格、Q/W/E/R/T
2. 每个按键可配：策略（禁用 / 连点 / 按住不放）、执行间隔（毫秒，下限 50）、随机抖动（±15%）
3. 战斗宏启停热键默认 `F2`，仅 POE2 窗口激活时生效；启动时连点键首次触发随机错开避免同帧
4. 连点由 10ms 调度器按到期时间驱动（SendInput 发送），间隔精确不漂移；POE2 窗口失焦自动停止并释放所有按住键；`F12` 全局紧急停止并释放 Ctrl/Shift/Alt/鼠标键

### 背包一键存仓

1. 游戏窗口内：鼠标指向背包第 1 格中心按 `F3`，指向右侧相邻格中心按 `F4`，格子间距自动保存
2. 行数 / 列数 / 整理间隔在界面"功能设置"区调整（默认 5 × 11，间隔默认 30ms、±30% 随机抖动，范围 5-5000ms；整理为快速操作：鼠标瞬间移动 + Input 模式点击）
3. 鼠标放到第 1 格中心，按整理热键（默认 `F1`）开始：按住 Ctrl 按行优先遍历点击；整理中再按一次热键停止
4. 整理中窗口失焦或按 `F12` 自动中断并释放 Ctrl

### 旋风配置（数字检测触发）

「旋风」标签页是战斗宏的特殊配置页，用同一个战斗热键（默认 `F2`）启停：

1. 鼠标左 / 中 / 右键：与普通配置页相同，可配策略（禁用 / 连点 / 按住不放）、间隔、随机抖动
2. Q / E 技能改为**数字检测触发**：技能图标左上角出现数字（充能数）时自动按一下
   - ① 标定：点该行「标定」→ 游戏内鼠标指向技能图标上的数字按 `F5`（确定搜索范围中心，±30px）
   - ② 截图：点该行「截图」打开 FindText 工具 → 截取数字图像 → 生成字库代码点 Copy → 粘贴到该行输入框（`[Cyclone]` 节 `q_text`/`e_text` 持久化）
   - ③ 检测：有字库代码时用 FindText 图像匹配（容错 10%），未截图时用白色像素兜底；每 2 秒一次（测试阶段）
   - 边沿触发：数字从消失到出现只按一次，不会连按
   - 调试日志：每次检测写入 `ahk/cyclone_debug.log`（方式/中心色/检测结果/是否按键），启动时重置
3. **Q / E 优先级高于鼠标按键**（同一调度节拍内先检测 Q/E 再发鼠标键）

### 坐标页（货币坐标管理）

「坐标」标签页集中管理所有脚本用到的货币坐标，从 ini（`[Currency]` 节）读取并展示（双列布局：左列三级货币、右列普通货币）：

- 三级货币：蜕变 / 增幅 / 富豪 / 崇高 / 混沌，只需标定**一级**坐标；二级 = 一级 +70px、三级 = +140px（向右推导）
- 普通货币：点金石 / 瓦尔 / 磨刀石 / 护甲片 / 奥术师
- 标定方法：点该行「标定」→ 切到游戏窗口，鼠标指向该货币按 `F5` 记录（再点一次「标定」取消）；坐标立即写入 ini 并刷新显示

### 石碑速点

按住 Shift → 移动到所选货币坐标右键选中 → 移动到背包逐格左键 → **完成后自动触发一次背包整理**，批量把货币应用到石碑/装备上：

1. 「坐标」页标定所用货币坐标，F3/F4 标定背包格距
2. 功能设置区选择石碑货币与级别（级别仅对三级货币生效）、石碑间隔（默认 50ms，±30% 抖动，范围 5-5000ms）
3. 游戏内鼠标放到背包第 1 格中心，按石碑速点热键（默认 `F6`）开始；再按一次停止
4. 失焦或按 `F12` 自动中断并释放 Shift（中断时不触发整理）

### 地图速点

按顺序执行：点金石×每格 1 次 → 崇高×每格 4 次 → 瓦尔×每格 1 次 → **完成后自动触发一次背包整理**，批量给地图上点金/崇高/瓦尔：

1. 「坐标」页需已标定：点金石、崇高（一级）、瓦尔；F3/F4 标定背包格距
2. 地图间隔单独配置（默认 50ms，±30% 抖动，范围 5-5000ms）
3. 游戏内鼠标放到背包第 1 格中心，按地图速点热键（默认 `F7`）开始；再按一次停止
4. 每个阶段都是"Shift 按住 → 货币坐标右键选中 → 背包逐格左键 N 次"；失焦或 `F12` 中断（中断时不触发整理）

修改配置后点"保存配置"生效（热键即时重注册）；关闭窗口自动保存并退出。

## 主界面（Python tkinter 旧版）

执行 `uv run python main.py` 启动，窗口分为：运行状态区、四模块标签页、共享日志区。

## 背包整理（Python 旧版）

一键存仓：以鼠标当前位置为第 1 格中心，按住 Ctrl 按网格依次点击，把物品转移到仓库。

### 使用方式

1. 打开 POE2 背包界面（同时打开仓库页）
2. 鼠标移到某格中心按 `F3`，移到同一行右侧相邻格中心按 `F4`，格子间距自动保存
3. 按需调整行数 / 列数（默认 5 × 11），点"保存背包设置"
4. 鼠标放到第 1 格中心，按整理热键（默认 `F1`）开始整理；整理中再按一次热键停止
5. `F12` 紧急停止并释放所有按键（固定不可修改）

整理热键可在"背包整理"页点"设置热键"后按新键修改（按 Esc 取消）。

### 状态说明

- 运行状态区实时显示：POE2 是否前台、是否已标定、整理是否运行中
- POE2 窗口失焦会自动停止整理

## 战斗

战斗巡航（连点宏）：启动后按各按键配置周期触发，直到停止或 POE2 失焦。

### 使用方式

1. 在"战斗"页为每个按键配置策略（禁用 / 连点 / 按住不放）与执行间隔（默认 300ms，下限 50ms），点"保存战斗设置"
2. 支持按键：鼠标左键、鼠标右键、空格、Q/W/E/R；默认鼠标左键连点，其余禁用
3. 游戏中按启停热键（默认 `F2`）启动/停止；启停热键可点"设置热键"修改（按 Esc 取消）
4. 连点间隔带 ±15% 随机抖动；POE2 窗口失焦自动停止并释放所有按键
5. `F12` 紧急停止所有任务并释放按键

## 经济记录（Web 应用）

独立的 Web 应用，记录 poe2db.tw 14 个经济模块的价格快照，与桌面工具互不影响。

### 启动

`uv run python -m web.app`，浏览器打开 http://127.0.0.1:8321 。

### 使用方式

1. 首次使用在「赛季管理」面板录入赛季名称与开服日期（如 0.5.5闪回 / 2026-09-04）；左侧赛季列表默认选中当前赛季（开服日期最新者），新旧赛季数据都保留可查
2. 左侧选择经济模块（通貨/碎片/祭祀等 14 个），点「刷新本模块」抓取该模块当前价格；刷新中按钮转圈禁用
3. 表格复刻原站：图标 + 繁体名 + 英文小字 + Wiki 链接、24h Value（含 ≈N 混沌换算）、7 天迷你走势 + 红/绿涨跌幅、24h 交易量
4. 表头点击可按价格/涨跌幅/交易量排序（升降切换）；搜索框同时匹配中文与英文名
5. 「开服天数」下拉筛选历史快照（开服天数 = 快照日期 - 开服日期 + 1），默认最新
6. 「定时抓取配置」面板：开关、开服 ≤ N 天（默认 14）每天定时抓、之后每周定时抓；保存后立即生效
7. 价格基准为神圣石；抓取「通貨」模块时自动更新混沌⇄神圣汇率，其他模块价格据此换算出 price_chaos

### 交易助手（左侧边栏「工具」区）

根据用户在游戏内观测并手动录入的兑换比例，计算最优兑换路径与套利机会，目标是根据差价快速积攒通货。所有录入永久保存（`trade_rates` 表），为后续智能优化积累数据。

1. **三通货互换比例**：崇高石 / 混沌石 / 神圣石 6 个兑换方向全部平铺展示，逐行录入（如 1 神圣 = 300 混沌），同一方向重复录入时以最新一条为准，旧记录保留在历史中
2. **物品兑换比例**：任意物品与三通货之间的比例，3 通货 × 买卖 2 方向共 6 行全部平铺展示（买卖价差需分别录入）；物品名带已抓取物品的名称联想
3. **最佳兑换方案**：以每个方向的最新比例构建汇率图，用简单路径 DFS 求三通货两两之间兑换率最高的路径（可绕行物品），绕行优于直兑时标注「绕行更划算」
4. **套利机会**：自动枚举乘积 > 1 的兑换环（如 神圣→崇高→混沌→神圣 增值 3%），按收益率降序展示
5. **录入历史**：最近 30 条记录，误录可删除
6. 计算逻辑在 `web/trading.py`（纯函数），单测覆盖最优路径与套利环检测
