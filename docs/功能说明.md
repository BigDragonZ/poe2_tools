# 功能说明

> 功能文档：解释各模块功能及使用方式，含待完成清单（人工验证后更新状态）。

## 主界面

执行 `uv run python main.py` 启动，窗口分为：运行状态区、四模块标签页、共享日志区。

## 背包整理

一键存仓：以鼠标当前位置为第 1 格中心，按住 Ctrl 按网格依次点击，把物品转移到仓库。

### 使用方式

1. 打开 POE2 背包界面（同时打开仓库页）
2. 鼠标移到某格中心按 `F3`，移到同一行右侧相邻格中心按 `F4`，格子间距自动保存
3. 按需调整行数 / 列数（默认 5 × 11），点"保存背包设置"
4. 鼠标放到第 1 格中心，按整理热键（默认 `F1`）开始整理；整理中再按一次热键停止
5. `F12` 紧急停止并释放所有按键（固定不可修改）

整理热键可在"背包整理"页点"设置热键"后按新键修改（按 Esc 取消）。

### 状态说明

- 运行状态区实时显示：POE2 是否前台、是否已标定、整理是否运行中
- POE2 窗口失焦会自动停止整理

## 战斗

战斗巡航（连点宏）：启动后按各按键配置周期触发，直到停止或 POE2 失焦。

### 使用方式

1. 在"战斗"页为每个按键配置策略（禁用 / 连点 / 按住不放）与执行间隔（默认 300ms，下限 50ms），点"保存战斗设置"
2. 支持按键：鼠标左键、鼠标右键、空格、Q/W/E/R；默认鼠标左键连点，其余禁用
3. 游戏中按启停热键（默认 `F2`）启动/停止；启停热键可点"设置热键"修改（按 Esc 取消）
4. 连点间隔带 ±15% 随机抖动；POE2 窗口失焦自动停止并释放所有按键
5. `F12` 紧急停止所有任务并释放按键

## 经济记录（Web 应用）

独立的 Web 应用，记录 poe2db.tw 14 个经济模块的价格快照，与桌面工具互不影响。

### 启动

`uv run python -m web.app`，浏览器打开 http://127.0.0.1:8321 。

### 使用方式

1. 首次使用在「赛季管理」面板录入赛季名称与开服日期（如 0.5.5闪回 / 2026-09-04）；左侧赛季列表默认选中当前赛季（开服日期最新者），新旧赛季数据都保留可查
2. 左侧选择经济模块（通貨/碎片/祭祀等 14 个），点「刷新本模块」抓取该模块当前价格；刷新中按钮转圈禁用
3. 表格复刻原站：图标 + 繁体名 + 英文小字 + Wiki 链接、24h Value（含 ≈N 混沌换算）、7 天迷你走势 + 红/绿涨跌幅、24h 交易量
4. 表头点击可按价格/涨跌幅/交易量排序（升降切换）；搜索框同时匹配中文与英文名
5. 「开服天数」下拉筛选历史快照（开服天数 = 快照日期 - 开服日期 + 1），默认最新
6. 「定时抓取配置」面板：开关、开服 ≤ N 天（默认 14）每天定时抓、之后每周定时抓；保存后立即生效
7. 价格基准为神圣石；抓取「通貨」模块时自动更新混沌⇄神圣汇率，其他模块价格据此换算出 price_chaos
