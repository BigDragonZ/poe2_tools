# 菜单体系三级嵌套标准（2026-10-03）

## 变更内容

- 确立全应用统一菜单标准并落地到 `web/static/index.html`：
  1. 顶部为一级菜单（经济 / 策略 / 做装 / 开荒）
  2. 左侧边栏为二级菜单（`.side-l2`，纯分组标签，不可点击）
  3. 三级菜单（`.side-item.sub`，即页面）缩进嵌套在所属二级菜单下方，点击切换内容区
  - 以后所有新增页面必须按此标准接入，不允许在内容区自设菜单列
- 做装页（此前严重偏离标准）：三级页面「稀有度」从内容区模块列移入侧边栏，嵌套在二级菜单「戒指」下方；内容区直接展示流程图；`CraftPage` 改为接收 `section` + `page` 属性，三级页面状态提升到 App 层（`craftPage`），不再自持
- 经济页同步对齐：内容区左侧的「经济模块」模块列（14 个模块）与侧边栏「工具」区（交易助手/信息库）统一改为侧边栏二级菜单「经济模块」/「工具」+ 其下嵌套的三级页面；赛季切换区保留在侧边栏顶部，属于数据切换不属于菜单层级
- App 层新增 `ecoView` 状态（module / trade / library）区分经济一级菜单下的三级页面；顶部「经济」active 判定改为 `page === "economy"`
- 移除不再使用的 `.content-row` / `.module-col` / `.table-col` 样式与结构
- `web/browser_check.py` 同步更新菜单断言：二级菜单文本、三级菜单数量（14 模块 + 2 工具）、三级菜单嵌套在侧边栏且主内容区无模块列、做装页「戒指 → 稀有度」嵌套结构、新增信息库三级页面可达检查
- `docs/功能说明.md` 新增「菜单体系标准」小节，并更新交易助手/信息库/做装三节的菜单位置描述
