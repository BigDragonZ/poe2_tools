# 2026-09-30 AHK 按键助手（桌面端重构）

## 背景

Python（pydirectinput/keyboard）键鼠模拟在 POE2 中适配性一般，按用户要求参考 D3KeyHelper v1.4（`temp/D3.AHK.v1.4.230222/d3keyhelper.ahk`，AHK v1）将桌面端功能重构为 AutoHotkey v2 脚本。

## 变更

- 新增 `ahk/poe2_key_helper.ahk`（AHK v2，约 440 行）：
  - **战斗宏**：配置 1-4 四个配置页，每页 13 个按键（左键/右键/空格/Q/W/E/R/T/1-5），每键可配策略（禁用/连点/按住不放）、执行间隔（下限 50ms）、随机抖动（±15%）；连点采用每键独立 `SetTimer`（复用 BoundFunc 避免定时器泄漏），首次触发随机错开；失焦自动停止（定时器内检查 + 200ms 看门狗双保险）
  - **背包一键存仓**：F3/F4 两点标定（仅保存水平间距 CellSize，校验第 2 格在右侧同一行 ±10px）；以触发时鼠标位置为第 1 格中心，按住 Ctrl 行优先遍历点击，格子坐标 `x=ox+col*cell, y=oy+row*cell`，移动/点击均带随机延迟；再按热键或失焦中断，`finally` 中释放 Ctrl
  - **紧急停止**：全局 `F12`，停止一切并释放 Ctrl/Shift/Alt/鼠标左右键；退出脚本（`OnExit`）同样释放
  - **热键作用域**：战斗（默认 F2）/整理（默认 F1）/标定（F3/F4）仅 POE2 窗口激活时生效（`HotIfWinActive`），F12 全局；配置保存后热键即时重注册
  - **配置持久化**：`ahk/poe2_key_helper.ini`（UTF-8），`[General]` + `[Bag]` + 每配置页一个 `[配置N]` 节；切页自动同步内存、保存按钮/关窗写盘
  - 发送模式固定 `SendMode "Event"`（与 D3 版一致）
- Python tkinter 版（`poe2_tools/bag.py`、`combat.py`、`ui/`）保留备用，不再继续投入
- 文档同步：`AGENTS.md`（当前阶段/技术栈/代码组织/运行方式）、`docs/项目框架.md`（技术栈/目录/模块规划）、`docs/功能说明.md`（新增 AHK 章节 + 待验证项）
