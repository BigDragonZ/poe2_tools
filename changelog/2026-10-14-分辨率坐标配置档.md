# 2026-10-14 分辨率坐标配置档

## 背景

换分辨率后所有坐标需全量重测、旧配置只能手工备份（见 `changelog/2026-10-13-分辨率变更坐标重测.md`），来回切换分辨率极其麻烦。

## 变更

启动桌面端时读取 POE2 客户区分辨率，自动激活该分辨率的坐标配置档；无档时提示并引导进入标定流程。

### ini 分档（config/settings.py）

- 坐标类段按 `基础段名@宽x高` 后缀分档：`[Sort@R]`（仅 CellSize）、`[StashUI@R]`、`[Currency@R]`、`[Measure@R]`；热键/间隔/Profile 等非坐标段不分档
- 读取回退规则（`_resolve_section`，杜绝跨分辨率坐标污染）：
  1. 当前分辨率档存在 → 只读档段
  2. 档不存在且无任何 `@` 变体（老配置）→ 回退基础段
  3. 档不存在但已有其他分辨率档 → 视为未标定，不读基础段
- `save_settings` 由全量重写改为读改写：自有段（含旧版 legacy 段）重写，其他分辨率档段原样保留；基础段照常全量写（= 最后使用快照），带分辨率时额外套写当前档
- `Settings` 新增 `resolution` / `coords_profile_exists` 字段与 `coords_profile` 属性；`load_settings(path, resolution=None)` 签名向后兼容
- 老配置零迁移成本：经规则 2 回退生效，首次保存即物化为当前分辨率档

### 启动挂接（ui/app.py）

- `configure_window_title` 前移到 `_load_settings` 之前（分辨率检测依赖窗口标题绑定）
- `_load_settings` 先 `window.client_size()` 检测分辨率，三种启动日志：窗口未开（WARN 未激活）/ 档缺失（WARN 引导 F3/F4/F5 标定）/ 正常（显示档名）
- Header 新增「坐标档」状态项（未激活 / 档名 / 档名+未标定），随状态轮询刷新
- 档缺失时启动后自动切到「研发-坐标」页引导标定
- 标定写入当前档零额外传递：所有标定路径走 `save_settings(self.settings)`，分辨率上下文在 Settings 上（F3/F4 → `[Sort@R]`，F5 货币/测量点 → `[Currency@R]`/`[Measure@R]`，框选 → `[Measure@R]`）

### 坐标页（ui/coords_tab.py）

- 标题说明改为动态显示当前档名（`未激活` / `1600x1024`）

## 范围说明（用户确认）

- 仅 ini 坐标分档；旋风模块 `modules/cyclone/config.json`（Q/E 数字区、血条 ROI）独立体系不参与
- 仅启动时检测一次；运行中不监听分辨率变化
