# 2026-10-04 应用管理脚本

## 背景

Web 应用重复启动时报 `Errno 10048`（端口 8321 被旧实例占用），需要手工查 PID、杀进程，操作繁琐。

## 变更内容

- 新增 `scripts/app.sh`：统一管理 Web 应用（`web.app`，端口 8321）与桌面端（`main.py`，tkinter）
  - `bash scripts/app.sh <start|stop|restart|status> [web|desktop|all]`，目标默认 `all`
  - Web 应用通过 `netstat` 查端口占用定位 PID；桌面端通过 PowerShell `Win32_Process` 匹配命令行 `main.py` 定位 PID
  - 结束前校验进程命令行含 `web.app` / `main.py`，避免误杀无关进程
  - 启动使用 `nohup ... & disown` 后台运行，日志输出到 `logs/web.log`、`logs/desktop.log`
  - 重复启动/关闭时幂等提示（已在运行 / 未在运行）
- 新增根目录 `应用管理.sh`：命令速查文档（仅记录命令，不直接执行）
  - 管理脚本用法、Git Bash 单条命令、PowerShell 单条命令、常见端口占用问题处理
- 同步 `AGENTS.md` 与 `docs/项目框架.md` 目录结构

## 验证

- `bash scripts/app.sh status`：正确识别运行中的 Web 应用与桌面端 PID
- `bash scripts/app.sh restart web`：关闭旧实例并重启成功，访问 http://127.0.0.1:8321/ 返回 200
