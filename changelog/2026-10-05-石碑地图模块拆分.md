# 2026-10-05 石碑/地图速点提取为独立导航模块

## 变更内容

- 石碑速点、地图速点从「通用」页拆出，成为独立导航模块；导航从 4 个变为 6 个：战斗 / 通用 / 石碑 / 地图 / 研发 / 交易
- 新增 `poe2_tools/ui/tablet_module.py`（石碑模块：热键 + 货币/级别 + 间隔，`current_page()` 返回 `tablet`）
- 新增 `poe2_tools/ui/map_module.py`（地图模块：热键 + 间隔，`current_page()` 返回 `map`）
- `poe2_tools/ui/general_module.py` 瘦身为「背包网格（通用，整理/石碑/地图共享）+ 背包整理」，`current_page()` 仍返回 `sort`
- `poe2_tools/ui/app.py` 接线：导航 `MODULES`、StackedView 注册、load/sync 同步、`_modules` 作用域表；热键注册/急停/状态轮询逻辑不变（业务 runner 本就分开）
- 热键捕获辅助代码按「复制后独立适配，不抽公共包」原则在各模块文件内各自保留一份
- 配置模型与 ini 段（`[Tablet]` / `[Map]`）不变，兼容现有配置

## 不变部分

- 业务层 `modules/waystone.py`、`modules/map_runner.py` 本就是独立单文件，未移动未改名
- 功能热键仍与页面无关（POE2 前台即生效），F12 急停全局

- `uv run pytest`：260 项全绿
- 导入冒烟：`poe2_tools.ui.app` / `general_module` / `tablet_module` / `map_module` 正常
- 游戏内行为（热键、标定、保存写盘）待人工验证
