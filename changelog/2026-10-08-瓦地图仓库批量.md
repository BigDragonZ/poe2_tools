# 2026-10-08 瓦地图（仓库批量取图 → 打造满 6 词 → 瓦尔 → 存回）

## 需求

通用功能优化第一项：瓦地图完整流程自动化。

1. 打开 Map → 目标阶级（默认 XV）地图页，逐格查看地图
2. 非已汙染且词缀数不满 6 的地图，Ctrl+左键移至背包
3. 过滤完成后仓库切至通货页
4. 点金 → 崇高补满至 6 词缀 → 瓦尔
5. 瓦完后 Ctrl+左键全部存回仓库

## 前置信息获取（2026-10-05 游戏内实测）

- 仓库界面坐标（2560×1440 客户区）：通货/Map 等列表项、I-XVI 阶级按钮（两行各 8）、仓库页 1-6 绿色按钮、Map 仓库 8×12 格（首格中心 (82,483)、格距 65）、背包 5×12 格（首格中心 (1731,816)、格距 70）
- 悬停 + Ctrl+C 可从剪贴板读取物品完整文本（含种类/稀有度/阶级/词缀/「已汙染」标记），空格不改写剪贴板 → 剪贴板哨兵判空
- 词缀数按 `{ 前綴/後綴 }` 头计数（单条词缀可占多行）；0.3.1 起点金石可直接用于魔法物品升稀有（官方论坛确认）
- 通货坐标直接复用「坐标」页已标定的 `[Currency]`（点金/崇高/瓦尔），不重复标定

## 实现

- `poe2_tools/core/clipboard.py`（新增）：剪贴板读写（win32clipboard 懒导入 + 占用重试）
- `poe2_tools/modules/map_vaal.py`（新增）：
  - 纯逻辑：`parse_waystone`（Ctrl+C 文本 → 稀有度/阶级/词缀数/已汙染）、`needs_craft`、`craft_action`（普通/魔法→点金，稀有未满→崇高，满 6 词→瓦尔）、`tier_button`/`page_button`（坐标推导）
  - `MapVaalDriver`：客户区坐标点击、Ctrl+点击（try/finally 释放）、悬停 Ctrl+C 读物品文本（哨兵判空）、仓库开启检测（面板右缘亮度采样，开≈40/关≈120；注意用 RGB 三通道求均值，raw 含 Alpha=255 会误判）
  - `MapVaalRunner(ToggleRunner)`：三阶段（取图 → 打造 → 存回）；取图带复读校验（格子未空 = 背包已满即停）；打造逐次复读校验状态，同一货币连续 2 次无变化判失败跳过（未满 6 词不瓦），单图 8 次应用上限防死循环；中断/失焦/F12 立即停止
- `poe2_tools/config/settings.py`：新增 `[MapVaal]`（Hotkey 默认 ctrl+f7 / Interval / Tier 默认 15）与 `[StashUI]`（仓库界面布局，默认值为 2560×1440 实测，分辨率不同改 ini）
- UI：「地图」模块新增瓦地图配置区（热键 + 间隔 + 阶级）；`app.py` 四处接线（构造 / 热键注册 / 状态区「瓦图中」/ F12 急停）
- 测试：`tests/test_map_vaal.py` 14 项（真实 Ctrl+C 样本 fixtures 解析 + 过滤/打造决策 + 取图过滤/背包已满/白图全流程/失败不瓦/存回序列，假驱动注入）

## 流程优化（2026-10-08 用户确认）

1. 点阶级按钮后先点回第 1 页，从第 1 页开始取图
2. 取图计数并设容量上限：背包最左列为保留列，可用格子 = 通用页 行×列（默认 5×11=55），取满即停
3. 存回按词缀分流：非 8 词 Ctrl+左键（自动归入对应阶级页）
4. 8 词图最后统一点「高级地图」仓，Ctrl+Shift+左键强制存入该页（`[StashUI] TabAdvancedMap`，默认 (975,828)）

## 流程优化第三轮（2026-10-10 用户确认）

1. 每页先截图做 OpenCV 占用检测（单帧灰度逐格均值，空格≈8 / 有物品≥58，阈值 30），无地图的页整页跳过；只对有物品的格子悬停 Ctrl+C 读取，空页从 96 次读取降为 1 次截图
2. 新增阶段零「取出背包里所有未鉴定的地图」：切到 Map 页后先扫描背包，未鉴定换界石（Ctrl+C 文本含「未鑑定」）Ctrl+左键取回仓库；仓库里的未鉴定地图取图时跳过（读不到词缀无法过滤）
3. 打造阶段同样先截图检测背包占用格，只处理有物品的格子
